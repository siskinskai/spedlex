## 3. Summary

- **150 entries: 150 confirmed, 0 misplaced, 0 not found.** 14 needed a hand check. Section numbers in Section II all match the rule.
- **Mapping:** one problem. Entry 69 attests fetal alcohol spectrum disorder, but the rule names fetal alcohol syndrome, which is narrower.
- **Safety:** no single letters, no bare names. "state ward" contains the surname Ward and "Long Creek Youth Development Center" contains Long, but both are phrases. Facilities named for places carry `place_name`. MRSA, EF-S-01 and B-2 are not names.
- **Typing:** acronyms are typed `A`; Maine-only strings carry US-ME. "SAU" now has no state tag, as the drafter's second commit explains (New Hampshire uses it too).
- **Manifest:** both `doc_id`s have US-ME rows; `me-muser-emergency-2026` is declared in `UNCITED_DOCS`. No source file or long extract is in the change.
- **Docstring:** accurate. A sentence-level comparison of the two PDFs finds the differences it describes (the highly-qualified-teacher text, a new XVI(1-A) on private schools, and layout changes that move Section XVI by about a page). None of them adds a recorded term.

**Most important fixes**

1. Record "fetal alcohol syndrome" as its own concept under fetal alcohol spectrum disorder instead of attesting the broader concept.
2. Add ESEA, which SPEDLex lacks entirely.
3. Add the rule's own variant forms (homeless child, parentally placed private school child, continuum of alternate placements, least restrictive educational environment, self-contained special classrooms).
